# MealBot

**Telegram-бот для планирования меню из продуктов, которые уже есть дома.**

</div>

---

<div align="center">

## О проекте

</div>

MealBot помогает составлять меню на основе точных запасов пользователя. Пользователь добавляет продукты с количеством и единицей измерения, выбирает период, приёмы пищи и количество порций. Бот подбирает рецепты через ИИ, проверяет доступность ингредиентов, резервирует продукты для запланированных блюд и пересчитывает остатки после приготовления.

Проект реализуется как модульный монолит на C# и .NET 9. Telegram-бот работает в фоновом процессе, хранит данные в PostgreSQL и использует внешний OpenAI-совместимый сервис для генерации рецептов в структурированном JSON-формате.

---

## Пользовательский сценарий

```text
Добавить продукты
        ↓
Выбрать период, приёмы пищи и порции
        ↓
Получить и проверить рецепты
        ↓
Составить меню с учётом доступных остатков
        ↓
Приготовить, пропустить или заменить блюдо
        ↓
Пересчитать запасы и список покупок
```

Пример запаса:

```text
Курица — 1000 г
Яйца — 10 шт.
Молоко — 1000 мл
```

Главная клавиатура бота:

- «Мои продукты»;
- «Добавить продукт»;
- «Составить меню»;
- «Моё меню».

- добавление продукта через диалог;
- ввод точного количества;
- выбор единицы измерения: граммы, миллилитры или штуки;
- просмотр запасов;

- изменение количества и единицы измерения;
- удаление продукта;

- объединение одинакового продукта с одной единицей измерения;
- валидация через `FluentValidation`;
- защита от изменения и удаления зарезервированных продуктов.

### ✅ Этап 3 — настройка плана меню

- выбор периода от 1 до 7 дней;
- кнопки выбора: 1, 3, 5 и 7 дней;
- выбор нескольких приёмов пищи: завтрак, обед и ужин;
- выбор количества порций от 1 до 12;
- создание `MealPlan`;
- создание `PlannedMeal` для каждого дня и приёма пищи;
- сохранение плана и настроек в PostgreSQL;
- статусы плана и блюда: `Draft`, `Active`, `Completed`, `Cancelled`, `Planned`, `Cooked`, `Skipped`, `Replaced`.

### ✅ Этап 4 — генератор рецептов через ИИ

- добавлен интерфейс `IRecipeGenerator`;
- реализован `OpenAiRecipeGenerator`;
- поддержан OpenAI-совместимый endpoint Chat Completions;
- в запрос передаются продукты и точные остатки, приём пищи, порции, максимальное время и список исключённых блюд;
- ответ запрашивается по строгой JSON Schema;
- проверяются название, приём пищи, порции, время, ингредиенты и шаги приготовления;
- обрабатываются ошибки API, сети, тайм-ауты и некорректный JSON;
- предусмотрено до трёх попыток генерации;
- ошибки предыдущих попыток передаются генератору.


### ✅ Этап 5 — проверка рецептов

- добавлен RecipeValidator для бизнес-проверки ответа ИИ;
- проверяются название, приём пищи, порции, время, ингредиенты и инструкция;
- проверяются положительные количества и поддерживаемые единицы измерения;
- добавлен справочник ProductAliases для сопоставления вариантов названий;
- неизвестные продукты отклоняются;
- ингредиенты приводятся к каноническим продуктам из справочника;
- проверяется доступный остаток с учётом разрешения на недостающие ингредиенты;
- в результате проверки сохраняется количество, которого не хватает для списка покупок;
- одинаковые ингредиенты объединяются до проверки остатков;
- добавлена защита от повторения блюд в одном меню;
- после ошибки автоматически запрашивается новый вариант, максимум три попытки;
- ошибки предыдущей проверки передаются генератору в следующем запросе.

## Модель данных

### Реализовано

- `Users` — пользователи и Telegram ID;
- `Products` — нормализованный справочник продуктов;
- `ProductAliases` — варианты названий одного продукта;
- `InventoryItems` — запасы, единицы измерения, количество и резерв;
- `MealPlans` — настройки плана меню;
- `PlannedMeals` — слоты блюд внутри плана.

### Будет добавлено

- `Recipes` — сохранённые рецепты;
- `RecipeIngredients` — ингредиенты рецептов;
- `PlannedMealIngredients` — требуемые, зарезервированные и недостающие ингредиенты блюда;
- `ShoppingListItems` — список недостающих продуктов.

## Генерация рецептов

Для генератора передаются:

- список доступных продуктов;
- точное количество каждого продукта;
- выбранный приём пищи;
- количество порций;
- максимальное время приготовления;
- уже использованные блюда;
- ошибки предыдущих попыток, если нужна повторная генерация.

Ожидаемый ответ имеет структурированный вид:

```json
{
  "name": "Курица с рисом и помидорами",
  "mealType": "Lunch",
  "servings": 2,
  "cookingTimeMinutes": 35,
  "ingredients": [
    {
      "productName": "Курица",
      "quantity": 400,
      "unit": "Gram",
      "isOptional": false
    }
  ],
  "steps": [
    "Промыть и отварить рис.",
    "Нарезать и обжарить курицу."
  ]
}
```

До добавления рецепта в меню должны выполняться дополнительные проверки:

- продукт существует в справочнике или сопоставляется через `ProductAliases`;
- единица измерения поддерживается;
- количества ингредиентов положительные;
- требуемое количество не превышает свободный остаток;
- приём пищи и порции соответствуют запросу;
- блюдо не повторяет уже добавленные блюда;
- инструкция содержит хотя бы один шаг.

## Запуск

### CI/CD

GitHub Actions выполняет восстановление зависимостей, сборку и unit-тесты для каждого push и pull request в `master`.

После успешного push в `master` workflow публикует приложение `MealBot.Bot` в артефакт `mealbot-<commit-sha>`. Артефакт можно скачать из завершённого запуска GitHub Actions и развернуть на сервере с .NET 9. Подключение автоматического выкладывания на конкретный сервер требует выбрать хостинг и добавить его секреты в настройках репозитория.

### Требования

- .NET SDK 9.0;
- Docker Desktop с поддержкой Docker Compose;
- токен Telegram-бота от BotFather;
- API-ключ сервиса генерации рецептов.

Дополнительные настройки генератора находятся в `src/MealBot.Bot/appsettings.json`:

```text
RecipeGenerator:BaseUrl
RecipeGenerator:TimeoutSeconds
RecipeGenerator:MaxAttempts
RecipeGenerator:RetryDelayMilliseconds
```

### PostgreSQL

```bash
docker compose up -d postgres
```

PostgreSQL будет доступен на `localhost:5433`. Миграции применяются автоматически при запуске бота.

### Telegram-бот

```bash
dotnet run --project src/MealBot.Bot/MealBot.Bot.csproj
```

После запуска отправьте боту:

```text
/start
```

### Остановка

```bash
docker compose down
```

Для полного удаления контейнера и данных PostgreSQL:

```bash
docker compose down -v
```
